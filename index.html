产品介绍

装在自己电脑上的量化研究工作台，数据留在本机，不注册、不登录。

AlphaDesk 是一个面向个人投资者的单机量化研究终端。 它把机构研究员日常用的三件事——因子筛选、策略回测、AI 辅助分析—— 做成了一个双击即用的软件：无需 Python 环境、无需配置数据库、无需上传任何数据。

🎯 为散户真需求设计

  • 不需要写代码：选股条件用下拉框点选
  • 不需要懂英文：全中文界面，指标都说人话
  • 不需要盯盘：收盘定时跑，命中推送重点信息

🔒 数据完全私有

  • 自选池、策略、分析记录全部存本机
  • 不注册账号、不收集手机号
  • 行情缓存也在本地，断网可看历史数据

🧪 不骗自己

  • 回测含佣金/印花税/滑点，T+1 开盘成交
  • 涨停买不进、跌停卖不掉，真实模拟
  • 默认开启样本内外检验，过拟合当场现形

常见问题

点击问题展开答案。
软件需要什么配置？会不会很吃电脑？
Win10/11 或 macOS 均可，普通办公本足够。计算主要在本机 CPU，日常使用（看盘+收盘跑一次）占用很低；全市场扫描时风扇会响一会儿，属正常。
需要自己装 Python 或数据库吗？
不需要。软件是打包好的独立程序，双击即用。数据使用内置轻量数据库，自动创建、自动维护。
数据准确吗？和券商软件一致吗？
行情来自公开渠道，日线使用前复权口径，与常见行情软件显示一致。数据可能存在延迟或个别缺失，重要决策请以券商软件为准。
选出来的股票能直接买吗？
不能，也不建议。本软件是研究工具：它帮你从几千只股票里缩小范围，最终的买卖判断必须由你自己做出。所有结果均不构成投资建议。
回测收益很漂亮，实盘能复现吗？
不一定，这是所有回测的共性。我们已尽量降低乐观偏差：含交易成本、T+1 开盘成交、涨停买不进、跌停卖不掉、并默认开启样本内外检验。如果样本外一栏是"由正转负，不可用"，请相信这个结论而不是样本内的漂亮数字。
换电脑了怎么办？
把整个软件文件夹拷到新电脑即可（数据跟着走）。激活码与本机绑定，换机需要联系卖家重新获取，年卡用户免费换机。
我的自选股和策略会被上传吗？
不会。软件为纯单机运行，无账号体系，所有数据只在你本机的 data 目录里。断网也能查看已有数据和回测记录。
AI 功能需要额外付费吗？
AI 分析使用你自己配置的接口密钥，费用由你与接口服务商结算，软件本身不额外收费。不配置密钥时，选股、回测、因子分析等核心功能完全可用。
支持港股吗？
支持。选股与回测的范围可选 A 股、港股或两者合并。
能开发票吗？
可以，请联系卖家说明开票信息。
