一、安装与启动

Mac（稳定版）

  1. 从 Releases 下载 AlphaDesk-*-mac.zip，解压得 AlphaDesk.app，拖进"应用程序"。
  2. 打开"终端"，粘贴回车：xattr -cr /Applications/AlphaDesk.app（App 在哪就写哪）。
  3. 右键点击 App → 打开，确认一次。以后双击即用。
  4. 图标进 Dock，约 3 秒后浏览器自动打开 http://127.0.0.1:8200。

Windows（公测版）

  1. 下载 AlphaDesk-*-win-beta.zip，解压到桌面（路径不要有中文）。
  2. 双击 start.bat。黑窗口一闪即后台运行，属正常。
  3. 浏览器自动打开 http://127.0.0.1:8200；没打开就手动输。
  4. SmartScreen 拦截点"更多信息 → 仍要运行"；杀毒误删就加白名单后重解压。

三、第一步：建自选池

  1. 首页弹窗点"一键导入示例"，10 只各行业龙头先填满（已有股票不会被覆盖）。
  2. 右上角"新增"手动加你关心的票，支持分组（默认/自建分组）。
  3. 点击任意一行看个股详情：评分、信号、AI 摘要、新闻公告。

建议：先 10~30 只。池子是后面所有功能（选股范围、收盘扫描、持仓）的地基。

四、第二步：一句话选股

  1. 左侧进「智能选股器」，输入框写人话，例如：连续下跌后出现止跌信号的股票。
  2. 范围选"仅自选池"（快，几十秒）或"A股全市场"（慢，几十分钟，后台跑）。
  3. 断点续跑：全市场筛到一半关了页面/电脑？重跑同条件，已扫过的秒过，只补没扫的。
  4. 点"筛选"，进度条走完看命中列表。点"试试"旁边的例句可直接体验。
  5. 结果可"存为方案"（以后收盘自动跑+命中推送）、"一键回测"、"复制代码"（去券商 App 下单）。

写法技巧：用"或"表示任一满足；回放日期可填过去某天，验证"当时能不能选出来"。

五、第三步：回测验证（最重要的 10 分钟）

  1. 「量化实验室」→ 输条件（因子下拉框组合，或从选股器"一键回测"过来）。
  2. 先看两个数：条件胜率（过去 6 个月这个信号胜率，50% 以下直接扔）、样本外结论。
  3. 再看回测 KPI：年化、最大回撤（能不能接受先看这个）、夏普、胜率/盈亏比。
  4. 样本外"由正转负，不可用" = 策略已失效，信它，别信样本内的漂亮曲线。
  5. 满意点"🏆 生成战绩图"，出一张带水印长图（自己留档，别当收益承诺发）。

一句话：凡是经不起回测的感觉，都是错觉。红了就扔，不心疼。

六、第四步：模拟持仓盯盈亏

  1. 左侧「模拟持仓」→ 右上角"加持仓"，填代码、买入价、数量、买入日。
  2. 现价/市值/盈亏/盈亏率自动算，总成本/总市值/总盈亏一屏看完。
  3. 卖了就点删除。这只是个明白账，不连券商。

七、日常用法：每天 10 分钟

  1. 早上：电脑开着就行，不用管（软件只在收盘后干活）。
  2. 晚上：打开看「仪表盘」→ 重点信息（有没有新增命中/公告异动）→ 持仓盈亏。
  3. 电脑关机错过收盘：第二天顶部会出现琥珀色横幅"昨日收盘没跑"，点"一键补跑"。
  4. 定时方案：选股器"存为方案"后打开"收盘定时"开关，每天 15:10 后自动跑，命中只推新增。

八、阿罗：说人话，让软件干活 v1.0.3

右下角 🅰️ 悬浮钮点开就是阿罗（Alpha 音译），软件的操作助手。 和"AI 分析"（给结论）不同，阿罗是动手干活的：加自选、查评分、切页面，一句话搞定。

  1. 直接说股票名："把茅台加进自选""茅台现在什么价""宁德评分怎么样""贵州茅台资金面"。
  2. 复杂问题一次问："茅台和宁德哪个评分高"——阿罗会分别查、对比、给结论。
  3. 删自选/补跑要确认：不可逆的动作会先弹确认卡，点了"执行"才干，防止说错话酿祸。
  4. 收盘后主动找你：跑完流水线右下角出小红点，"今晚几条新消息、命中几只"。
  5. 没配 Key 也能用：8 类固定说法（加/删自选、查价、评分、资金面、切页面、补跑等）零成本秒回； 去「设置」配个 DeepSeek Key 后，人话全听懂（多轮决策：查→看结果→再查→回复）。

提醒：阿罗不给买卖建议，只给事实和风险提醒；大模型偶尔犯错， 删自选这类动作执行前请看一眼确认卡。试用到期后阿罗只能查不能改，激活即恢复。

十、资金面怎么看

  1. 在「仪表盘」点任意股票 → 详情抽屉 → 💰 资金面卡片。
  2. 先看资金评分（0-100，50 中性）与结论：吸筹 / 温和流入 / 分歧 / 转弱 / 派发。
  3. 再看5/10/20 日主力净额：三个都红＝资金持续进；出现一绿要注意分歧。
  4. 连续净流入天数：连续 3 天以上比单日大额更可信（单日可能是对倒）。
  5. 筹码结构：大资金买+散户卖＝集中（偏强）；大资金卖+散户接＝分散（偏弱）。
  6. 柱子图：红=当日净流入，绿=净流出，看出资金节奏比看数字快。

重要：公开资金流是按单笔金额大小分类的推算值，不等于真实主力意图， 只能当"佐证"不能当"信号"。请和技术面/基本面一起看。

十一、进阶：AI 自我进化

  1. 「量化实验室」→「自选进化」页签，设方向（比如做多+持有 5 天），点"开始进化"。
  2. AI 自动生成几百个候选策略，逐个回测，样本外不合格的淘汰。
  3. 去喝杯咖啡，回来在「进化历史」看冠军规则，不满意点"采用"进正式策略。

这不是"AI 炒股"，是"AI 替你试错"。冠军也请先过第五步的回测三问。

十二、换电脑 / 重新激活

  1. 重装软件（同一台）：放心重装，授权、自选、持仓都在（数据在软件外面），打开即用。
  2. 数据搬家：Mac 拷 ~/Library/Application Support/AlphaDesk；Windows 拷解压目录下的 AlphaDesk\data。
  3. 换电脑（年卡免费）：新电脑打开软件 → 授权弹窗"换电脑了？"→"生成换机申请串"→发给卖家→粘贴新激活码。

十三、故障排查

页面打不开 / 黑窗口一闪就没？
只开一个程序；换 Chrome/Edge 打开 http://127.0.0.1:8200；Windows 检查路径有无中文。
Mac 提示"已损坏"？
重跑 xattr -cr（见第一节），右键打开。软件没坏，是苹果拦截无公证应用。
全市场筛选特别慢？
正常：首次全市场几十分钟（后台跑，进度条可见）。跑完一次进缓存，改阈值重筛秒回。自选池本来就快。
行情数字不动 / 显示横线？
非交易时间无实时行情，显示上个交易日收盘。节假日、晚上都这样。
资金面显示不出来？
资金流接口偶发抽风，会自动隐藏该卡片（不影响其他功能），稍后刷新即可。
AI 功能没反应？
「设置」里填你自己的接口密钥。不填也不影响选股、回测、持仓全部核心功能。
